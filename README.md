# 小麦的成长计划

网页版家庭育儿手账，保存在 GitHub Pages 根目录的静态文件可以直接发布。「今天」展示近期照护关注、生长曲线、分类和月龄事项。打开「照护记录」可以记喂养、入睡或换尿布，添加并勾选自定义待办，按本机日历日期回看。打卡与收藏、经验一同备份，现有版本 1 的备份可以继续导入。底部「育儿笔记」提供出生到未满三岁的月龄时间线、知识库和本机经验。「知识库」支持汉语别名、家庭场景和已满月龄组合查询，例如输入「15个月」或「一岁半 袜子」。收藏和「我家的经验」写入访问者浏览器的本地存储，并可一同导出。

## 成长工具

从原地址打开显示「今天」。分享给家人可用 `?open=today` 或 `?open=journal`。既有知识卡、时间线和打卡链接继续指向相应内容。填写本机宝宝档案后，可看到近期预约、发育观察和亲子游戏。成长工具提供照护统计、体测曲线、疫苗与儿保、发育观察、月龄游戏、照片日签、家庭设置与就诊报告。通过照片日记或交班摘要主动分享，群友打开同一网页时使用各自的本机记录。

照片日记保存在 IndexedDB，其他网页版记录按类型和编号存入 localStorage。备份文件包含这些私人数据。部署只需要提交仓库中的公开静态资源。新字段均可选，旧版打卡和收藏备份可以继续导入。网页和原生 App 各自持有记录，需要时由使用者导出与导入。

## 更新手账

1. 在 `cards.json` 维护卡片的标题、原因、做法、观察点（`observation` 或活动的 `activity.observe`）、出处和关键词。活动出处用 `sources` 注册表的 `role` 区分养育指南、教育理念和社区经验。已经发布的卡片应保留原编号，家庭记录依靠它找到对应的卡片。
2. 在同文件的 `stages` 修改时间线各阶段的重点和推荐卡片。按已满月龄设置首尾相接的 `stage.window`；插画默认用阶段 ID，也可指定已有图片的 `art` 名。`activity.window` 为左闭右开的已满月龄区间，配合宝宝的参与信号使用。
3. 运行 `node scripts/prepare.mjs` 校验阶段、关联卡片、活动来源，并生成新版本的离线缓存。界面、插画或内容更新后都要执行。
4. 用 `python3 -m http.server 8000` 启动本地预览，检查时间线、知识索引和本机笔记，再发布到 Pages。

原始 41 张卡片的编号为 `card-01` 至 `card-41`。新增家庭活动采用 `edu-` 编号。备份和导入沿用第 1 版结构。

《蒙台梭利婴儿》专题从「育儿笔记 → 知识库」打开，分享链接为 `?open=montessori`。`book-review-data.js` 按 2021 英文电子版（eISBN 9781523514069）维护逐节对照：中文选题、英文定位、核对结论、对应卡片与改编说明。附录活动图按九张表归组。电子版缺少连续印刷页码，新增引用请核对真实小节名。医学话题只用于定位，给家长的操作建议需另核现行照护依据。`book-guide.js` 从逐卡引用生成章节导航，`book-resources.js` 维护出版社公开附件。小麦原创卡继续使用 `cards.json` 的稳定编号，沿用相同的打卡、收藏及家庭经验存储。

健康计划、出处与测量标准放在 `health-data.js` 和 `health-growth.js`。修改剂次、月龄或参考数值时请同时核对官方文件和覆盖范围。照护统计在 `care-trends.js`，照片及日签在 `diary.js`，家庭资料、备份结构及路由分别在 `growth-store.js`、`device-tools.js` 和 `growth.js`。

运行 `node --test tests/*.test.mjs` 检查数据与统计。已安装 Playwright 和 Chrome 的环境也可以运行 `node scripts/growth-browser.cjs` 验证手机布局、照片、报告、备份与离线访问。

「今天」的月龄清单用 `month-entries.js` 维护短标题、单步玩法、生活观察和就医提示。游戏通过卡片 ID 关联 `cards.json` 中的完整笔记，编辑短文案时保留 ID。游戏按本地日期打卡，发育观察保留首次日期，预约和实际接种分别记录。日签先展示封面，照护统计支持近 7 天与近 30 天。
