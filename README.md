# 小麦的成长计划

网页版家庭育儿手账，保存在 GitHub Pages 根目录的静态文件可以直接发布。首页的「今日打卡」支持一键记喂养、入睡或换尿布，也可以添加并勾选自定义待办，按本机日历日期回看。打卡与收藏、经验一同备份，现有版本 1 的备份可以继续导入。首页的七个阶段从出生排到周岁。「知识索引」支持汉语别名、家庭场景和月龄组合查询。收藏和「我家的经验」写入访问者浏览器的本地存储，并可一同导出。

## 更新手账

1. 在 `cards.json` 维护卡片的标题、原因、做法、出处和关键词。已经发布的卡片应保留原编号，家庭记录依靠它找到对应的卡片。
2. 在同文件的 `stages` 修改时间线各阶段的重点和推荐卡片。`activity.window` 为左闭右开的已满月龄区间，配合宝宝的参与信号使用。
3. 运行 `node scripts/prepare.mjs` 校验阶段、关联卡片、活动来源，并生成新版本的离线缓存。界面、插画或内容更新后都要执行。
4. 用 `python3 -m http.server 8000` 启动本地预览，检查时间线、知识索引和本机笔记，再发布到 Pages。

原始 41 张卡片的编号为 `card-01` 至 `card-41`。新增家庭活动采用 `edu-` 编号。备份和导入沿用第 1 版结构。
